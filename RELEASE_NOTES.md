# Python-only release notes

## Scope

This release intentionally contains Python exports rather than original `.ipynb` files. The exported source preserves the original calculations, configurations, assertions, paths, and execution order as documented by `SOURCE_PROVENANCE.json`. No notebook upload or software license is part of this release.

## Included

- Python source exports for the original collections and E1–E8 validation work.
- Deposited CSV/JSON numerical evidence and saved predictions.
- Frozen split definitions, result hashes, completion manifests, and paper-table provenance.
- Language-identification outputs indexed in `manifests/CLASSIFIER_PREDICTIONS.json`.
- CPU-only release validation through `scripts/validate_release.py`.
- Citation metadata in `CITATION.cff`.

## Supports

The original strict-generalization analyses use 315/67/68 meanings from the 450-meaning baseline block. E6/E7 use 444 common complete meanings and retain a 309/67/68 train/validation/test partition. E6/E7 primary attention support is 17,760 rows per system and regime, with 68 test meanings.

## Not included or not claimed as a single-command rerun

Raw attention tensors, model weights, corpus text, external Drive inputs, and some per-head blocks are not deposited. Full recollection requires the pinned upstream inputs and documented runtime layout. Dedicated replacement routines are not supplied for the separate fp32 cross-model point-correlation calculation or the exact nine language-family contrasts. The exact manually arranged manuscript figure artwork is not claimed to be generated by one command.

## Verification

Run:

```bash
python3 scripts/validate_release.py
```

This checks repository file presence, frozen split sizes, E6/E7 support counts, provenance references, and SHA-256 entries. It does not rerun model inference, COMET scoring, tensor analyses, or statistical fits.

## Release identity

When this branch is merged or tagged for submission, record the resulting commit hash in the IEEE submission record. The repository is Python-only; notebook availability is not claimed.
