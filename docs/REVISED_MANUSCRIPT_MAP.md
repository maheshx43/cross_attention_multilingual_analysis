artwork is generated by a single command. Language-ID classifier predictions are embedded in the deposited E5B/E6 tables

and indexed in [CLASSIFIER_PREDICTIONS.json](../manifests/CLASSIFIER_PREDICTIONS.json).

support, and model-specific null-test coverage are summarized in

[METHOD_NOTES.md](METHOD_NOTES.md). Run `python3 scripts/validate_release.py`

from the repository root to check release metadata and deposited-file references

without rerunning scientific analyses.
